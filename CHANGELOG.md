# Changelog

## [0.1.0]

### Added

- 20-command CLI toolchain (`dipjo new`, `init`, `run`, `repl`, `build`, `test`, `check`, `format`, `lint`, `add`, `remove`, `install`, `update`, `list`, `clean`, `docs`, `serve`, `doctor`, `version`, `help`)
- Project scaffolding with `dipjo new`
- Project initialization with `dipjo init`
- Syntax checking without execution (`dipjo check`)
- Code formatting (`dipjo format`)
- Linting (`dipjo lint`)
- Build validation (`dipjo build`)
- Test runner (`dipjo test`)
- Dependency management (`dipjo add`, `remove`, `install`, `update`, `list`)
- Documentation generator (`dipjo docs`)
- Installation diagnostics (`dipjo doctor`)
- Project cleanup (`dipjo clean`)
- npm CLI packaging for global installation
- Cross-platform Python detection (Windows/macOS/Linux)
- HTTP server command (`dipjo serve`)
